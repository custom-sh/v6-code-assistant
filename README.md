# V6 Code Assistant Plugin

IntelliJ IDEA 插件，基于V6项目规范的代码助手工具。

## 功能特性

- 基于模板的代码生成（Column、Table、Model、Vue、Vo 、Menu等）
- 可视化配置面板，一键初始化项目模板、一键升级版本、构建项目
- 支持多端项目配置（服务端、Web端、PDA端）
- 支持多语言
- AI 接口预留（后期扩展）

## 构建

```bash
./gradlew buildPlugin
```

## 运行沙箱 IDE

```bash
./gradlew runIde
```

## 开发环境

- JDK 17+
- IntelliJ IDEA 2023.1+
- Kotlin 1.9.22
